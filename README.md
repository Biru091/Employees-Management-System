# Employee Task Management System (React)

A simple and efficient Employee Task Management System built using React.js.  
This project allows an admin to create, assign, and track tasks for employees with real-time status updates and persistent storage using Local Storage.

---

## Features

- Admin can create and assign tasks
- Employees can view assigned tasks
- Task statuses:
  - New Task
  - Active Task
  - Completed Task
  - Failed Task
- Task counting system for each employee
- Data persistence using Local Storage
- Fast UI with React Context API state management
- Real-time updates without page reload
